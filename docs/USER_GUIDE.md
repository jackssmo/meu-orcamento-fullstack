# Guia de uso

## Criar uma conta

1. Abra a tela de cadastro.
2. Informe nome, e-mail, senha e confirmação.
3. Entre com os dados cadastrados.

## Registrar uma transação

1. No dashboard, toque em **Nova Transação**.
2. Escolha **Receita** ou **Despesa**.
3. Informe descrição, valor, data e categoria.
4. Para uma receita mensal, marque **Renda Fixa**.
5. Para uma despesa parcelada, informe o número de parcelas.
6. Salve.

Novas transações começam com a data atual preenchida.

## Selecionar o mês

O dashboard exibe a evolução anual. Toque em uma barra ou no botão abreviado do mês. O período selecionado aparece no cabeçalho e atualiza:

- cards de resumo;
- lista de transações;
- gastos por categoria.

## Editar e excluir

Na lista de transações:

- use o lápis para editar;
- use a lixeira para excluir.

Excluir uma ocorrência de receita fixa também exclui seus próximos lançamentos. Despesas parceladas são excluídas individualmente.

## Gastos por categoria

O gráfico circular mostra a distribuição das despesas do mês. Cada categoria possui uma cor estável, além de exibir valor e percentual.

## Atualizar a conta

Abra **Minha conta** no menu lateral para alterar:

- nome;
- e-mail;
- senha.

A senha atual é necessária para confirmar a alteração.
